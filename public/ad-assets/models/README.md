# Vennet animation models

These are real editable GLB 3D models, not rendered images.

- vennet-portal.glb: emerald and chrome portal
- vennet-product-capsule.glb: digital-product capsule
- vennet-spark.glb: chrome and emerald spark
- vennet-automation-orb.glb: automation orb with orbit rings

Each file has named meshes and PBR materials. Import them into Blender, use them in Three.js / React Three Fiber, or open them in a glTF viewer.
